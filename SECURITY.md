# Security Policy

## Supported versions

Security fixes are applied to the latest release line. The `main` branch may contain work that is not yet released.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub Security Advisories for this repository when enabled, or contact the maintainer privately through the GitHub profile. Include a minimal reproduction, affected version, impact, and a safe mitigation if known. Do not include live credentials or production payloads.

ReplayWeave is designed to be local-only by default, but users remain responsible for reviewing bundles before committing them. Run `replayweave check` in strict mode and treat sanitized artifacts as potentially public.
