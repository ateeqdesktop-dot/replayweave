# Code of Conduct

ReplayWeave is committed to a welcoming, respectful, and harassment-free community. Participants must communicate constructively, assume good faith, respect different viewpoints, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, publishing private information, or any conduct that would make a reasonable contributor feel unsafe. Maintainers may remove comments, close discussions, or restrict participation when necessary to protect the community.

Report concerns privately to the repository maintainers through GitHub. All reports will be handled as confidentially as practical.
